# ຈັນທີ — ສຽງແຟນບານເຊຍສົດ & ອ່ານຄອມເມັ້ນຫຼັງເກມ

Joe ຂຽນພາສາລາວ — **ຕອບເປັນພາສາລາວ, ສັ້ນ**. ໃຫ້ພຽງ "ເກມ" ແລະ ຄວາມຍາວ ກໍ່ພໍ.

## ສຽງ (ຜ່ານການຮັບຮອງຈາກ Joe ແລ້ວ)
- **Voice**: `Zephyr` · **Model**: `gemini-3.8-flash-tts` (ໂມເດລທີ່ສ້າງຕົວຢ່າງທີ່ຜ່ານ; ໝົດໂຄຕ້າ → `gemini-3.8-flash-lite-tts` → `gemini-3.1-flash-tts-preview`, ສະຄຣິບປ່ຽນໃຫ້ເອງ ແລ້ວບອກ Joe ວ່າໃຊ້ໂມເດລໃດ)
- **Style**: `Warm, spirited, expressive young Lao female football fan-zone host. Lively post-match conversational pace with genuine laughs, excited sighs, and relatable fan reactions.`
- ຕົວຢ່າງທີ່ Joe ໃຫ້ຜ່ານ: `references/example-mu-liverpool.md` (ແມນຢູ 3–2 ລີເວີພູ, 28 ວິ) — ມາດຕະຖານນ້ຳສຽງ ແລະ ຈັງຫວະ.

## ຂັ້ນຕອນ
1. **ຄົ້ນຂໍ້ມູນ** (WebSearch 2–4 ແຫຼ່ງ): ຜົນ, ຜູ້ຍິງ + ນາທີ, ນາທີທີ່ລືມບໍ່ລົງ, ຄວາມໝາຍຂອງຜົນ.
   ອາລົມແຕ່ງໄດ້, **ຂໍ້ເທັດຈິງຫ້າມແຕ່ງ**. ແຫຼ່ງບໍ່ກົງກັນ → ເລືອກອັນໜຶ່ງ ແລ້ວບອກ Joe.
2. **ຄອມເມັ້ນແຟນ**: ໃຊ້ສະເພາະຄອມເມັ້ນທີ່ Joe ສົ່ງມາ ຫຼື ຫາໄດ້ຈິງ. ບໍ່ມີ → ຂ້າມພາກນີ້ ແລະ ເລົ່ານາທີສຳຄັນແທນ; **ຫ້າມແຕ່ງຄອມເມັ້ນແລ້ວອ້າງວ່າເປັນຂອງຄົນຈິງ**.
3. **ຂຽນບົດ** ເປັນ `.txt` ໃນ scratchpad (ໂຄງສ້າງລຸ່ມນີ້).
4. **ສ້າງສຽງ**:
   ```bash
   python3 <ໂຟນເດີ skill ນີ້>/scripts/tts.py <ບົດ.txt> <ຊື່>_Zephyr.mp3
   ```
   ສະຄຣິບບອກຄວາມຍາວ. ຫ່າງຈາກເປົ້າເກີນ ~10% → ເພີ່ມ/ຕັດປະໂຫຍກ ແລ້ວສ້າງໃໝ່ (ໂຄຕ້າຟຣີ ~10 ເທື່ອ/ມື້/ໂມເດລ).
5. **ສົ່ງ** MP3 ດ້ວຍ SendUserFile, ແລ້ວຕອບສັ້ນໆ: ຄວາມຍາວ, ໂມເດລທີ່ໃຊ້, ຂໍ້ເທັດຈິງ + ແຫຼ່ງ, ຄຳອ່ານຊື່ທີ່ຕ້ອງຟັງກວດ.

## ໂຄງສ້າງບົດ
| ຄວາມຍາວ | ປະມານ | ໂຄງ |
|---|---|---|
| 15–28 ວິ | ≈ 110–130 ຄຳ (ບົດທີ່ຜ່ານ ≈ 28 ວິ) | ອາລົມທັນທີ (0–3 ວິ) → ນາທີທີ່ລືມບໍ່ລົງ / ຄອມເມັ້ນແຟນ (3–18 ວິ) → `—` ຖາມຄະແນນເຕັມສິບ ຫຼື ຄວາມຮູ້ສຶກ (18–28 ວິ) |
| ~1 ນາທີ | ≈ 230–260 ຄຳ | ອາລົມທັນທີ → ເລົ່າເກມຕາມອາລົມ (ກັງວົນ → ລະເບີດ) → 2–3 ນາທີສຳຄັນ → ເຫັນໃຈແຟນອີກຝ່າຍ → `—` ຖາມຄະແນນ |

**ສູດ Hook 3 ວິ:**
1. `ໂອ້ຍທຸກຄົນ! ເບິ່ງຈົບແລ້ວຫົວໃຈຍັງເຕັ້ນບໍ່ເຊົາເລີຍ!` — ອາລົມສົດຫຼັງໝົດເວລາ
2. `ອ່ານຄອມເມັ້ນຫຼັງເກມຄືນນີ້ແລ້ວທັງຂຳທັງອິນ!` — ລວມຄອມເມັ້ນ
3. `ບອກຕົງໆວ່າເສຍດາຍແຮງ!` — ເຫັນໃຈແຟນ

## ກົດການຂຽນ (ໃຫ້ສຽງອອກມາດີ)
- **ເປີດດ້ວຍຄຳອຸທານ** (`ໂອ້ຍທຸກຄົນ!`) ໃຫ້ສຽງຟັງຄືຄົນເວົ້າສົດ ບໍ່ແມ່ນອ່ານບົດ.
- ໃສ່ `,` ຕົງຈຸດປ່ຽນອາລົມ (ມືເຢັນ → ຮ້ອງລັ່ນ); ໃສ່ `—` **ບ່ອນດຽວ** ກ່ອນຖາມແຟນ.
- **ຂຽນເປັນໂຕລາວທັງໝົດ**, ລວມທັງຊື່ (ເມນູ, ໂຊບົສໄລ, ກັກໂປ…); **ຕົວເລກເປັນຄຳ** (`ສາມຕໍ່ສອງ`, `ນາທີທີເຈັດສິບເຈັດ`, `ເຕັມສິບ`).
- ສຽງເພື່ອນແຟນບານລົມກັນ (ເດີ້, ແທ້ໆ, ເດ, ແດ່), ອາລົມຈິງ ແລະ ພາບໃກ້ຕົວ (ມືເຢັນໝົດ, ຮ້ອງຈົນໝາຂ້າງບ້ານເຫົ່າຕາມ).
- ບໍ່ໃຊ້ພາສາຜູ້ປະກາດຂ່າວ; ບໍ່ດ່າ ຫຼື ດູຖູກນັກເຕະເປັນສ່ວນຕົວ; ເວົ້າເຖິງແຟນອີກຝ່າຍແບບເຫັນໃຈ.
- ຈົບດ້ວຍຄຳຖາມໃຫ້ແຟນຕອບ (ຄະແນນເຕັມສິບ, ຊ່ວງທີ່ມັກທີ່ສຸດ) — ບໍ່ສະຫຼຸບແຫ້ງໆ.

## ຂໍ້ຈຳກັດທີ່ຕ້ອງບອກຕາມຄວາມຈິງ
- ຕ້ອງມີ `python3` ແລະ `ffmpeg` ໃນເຄື່ອງ, ແລະ ອິນເຕີເນັດອອກໄປ `generativelanguage.googleapis.com` ໄດ້.
- Claude ຟັງສຽງບໍ່ໄດ້ → ຂໍໃຫ້ Joe ຟັງຄຳອ່ານຊື່ນັກເຕະໃໝ່.

- ໂຄຕ້າຟຣີ ~10 ເທື່ອ/ມື້/ໂມເດລ. ໝົດທຸກໂມເດລ → ບອກ Joe (ລໍມື້ໃໝ່ ຫຼື ເປີດ billing).
