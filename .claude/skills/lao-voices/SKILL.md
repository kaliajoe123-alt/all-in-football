# ຄັງສຽງພາກລາວ (5 ສຽງທີ່ Joe ເລືອກ)

Joe ຂຽນພາສາລາວ — **ຕອບເປັນພາສາລາວ, ສັ້ນ**.

## ສຽງທີ່ມີ (Joe ຈັດອັນດັບເອງ — ໃຊ້ສະເພາະ 5 ສຽງນີ້)
| # | ຊື່ຫຼິ້ນ | ຕົວລະຄອນ | Gemini voice | ໃຊ້ກັບ |
|---|---|---|---|---|
| 1 | **(ດຸດັນ)** | ໂຄ້ດບອລ — ວິເຄາະແທັກຕິກ | Charon | ວິເຄາະເກມ, ແທັກຕິກ, ຈຸດປ່ຽນ, ຂ່າວຈິງຈັງ |
| 2 | **(ກວນດີ)** | ອ້າຍບ່າວຂ້າງບ້ານ — ພາກສາຍຮາ | Puck | ຄລິບຕະຫຼົກ, ແຊວບານ |
| 3 | **(ຜູ້ຍິງ)** | ຈັນທີ — ແຟນບານເຊຍສົດ | Zephyr | ຣີແອັກຫຼັງເກມ, ຊວນແຟນໃຫ້ຄະແນນ |
| 4 | **(ກວນ)** | ຟ້າໃສ — ປຸກກະແສກ່ອນເກມ | Puck | ກ່ອນເກມ, ນັບຖອຍຫຼັງ, ຊວນທາຍຜົນ |
| 5 | **(ກວນຕີນ)** | ມັງກອນທະລຸຕາຂ່າຍ — ລະເບີດສຽງຍິງປະຕູ | Fenrir | ຄລິບປະຕູ, ຍິງໄກ, ປະຕູນາທີສຸດທ້າຍ |

ຄ່າຕັ້ງ (voice, model, style) ຢູ່ `voices.json`; ບົດຕົວຢ່າງທີ່ Joe ຟັງແລ້ວ ຢູ່ `references/<#>_<ຊື່ຫຼິ້ນ>.md` — ໃຊ້ເປັນມາດຕະຖານນ້ຳສຽງ ແລະ ຈັງຫວະ.

## ຂັ້ນ 0 — ຖາມກ່ອນທຸກເທື່ອ (ບັງຄັບ)
ກ່ອນຂຽນບົດ ຫຼື ສ້າງສຽງ ໃຫ້ຖາມ Joe ວ່າເອົາສຽງໃດ, **ສະເພາະ 5 ສຽງນີ້**, ລຽງຕາມອັນດັບ, ມີຊື່ຫຼິ້ນໃນວົງເລັບສະເໝີ. ສົ່ງເປັນຂໍ້ຄວາມໃນແຊັດແບບນີ້ ແລ້ວລໍຄຳຕອບ:

```
ເອົາສຽງໃດ?
1. ໂຄ້ດບອລ (ດຸດັນ)
2. ອ້າຍບ່າວຂ້າງບ້ານ (ກວນດີ)
3. ຈັນທີ (ຜູ້ຍິງ)
4. ຟ້າໃສ (ກວນ)
5. ມັງກອນ (ກວນຕີນ)
```
- ໃສ່ ⭐ ແນະນຳ 1 ສຽງ ທີ່ເໝາະກັບເລື່ອງທີ່ສຸດ (ຕາມຖັນ "ໃຊ້ກັບ"), ແຕ່ຢ່າເລືອກແທນ Joe.
- ບໍ່ຖາມ ສະເພາະເມື່ອ Joe ບອກເລກ ຫຼື ຊື່ຫຼິ້ນມາແລ້ວ (ເຊັ່ນ "ເອົາ ກວນຕີນ", "ສຽງ 3").
- ບໍ່ສະເໜີສຽງອື່ນນອກລາຍການ (Kore, Aoede, mms, edge…), ເວັ້ນແຕ່ Joe ຂໍເອງ.

## ຂັ້ນຕອນຫຼັງເລືອກສຽງ
1. **ຄົ້ນຂໍ້ມູນ** (ຖ້າເປັນເກມ/ຂ່າວຈິງ, WebSearch 2–4 ແຫຼ່ງ). ມຸກ ແລະ ອາລົມແຕ່ງໄດ້, **ຂໍ້ເທັດຈິງຫ້າມແຕ່ງ**; ບໍ່ແຕ່ງຄອມເມັ້ນແຟນແລ້ວອ້າງວ່າເປັນຂອງຈິງ.
2. **ຂຽນບົດ** `.txt` ໃນ scratchpad ຕາມໂຄງຂອງສຽງນັ້ນ (ລຸ່ມນີ້) ແລະ ຍາວຕາມທີ່ Joe ຂໍ.
3. **ສ້າງສຽງ**:
   ```bash
   python3 <ໂຟນເດີ skill ນີ້>/scripts/tts.py <ບົດ.txt> <ຊື່>_<ຊື່ຫຼິ້ນ>.mp3 --pick <ເລກ ຫຼື ຊື່ຫຼິ້ນ>
   ```
   ຫ່າງຈາກຄວາມຍາວເປົ້າເກີນ ~10% → ເພີ່ມ/ຕັດປະໂຫຍກ ແລ້ວສ້າງໃໝ່.
4. **ສົ່ງ** MP3 ດ້ວຍ SendUserFile; ຕອບສັ້ນໆ: ສຽງ (ຊື່ຫຼິ້ນ), ຄວາມຍາວ, ໂມເດລ (ບອກຖ້າໃຊ້ໂມເດລສຳຮອງ), ຂໍ້ເທັດຈິງ + ແຫຼ່ງ, ຄຳອ່ານຊື່ທີ່ຕ້ອງຟັງກວດ.
5. ຢາກໃສ່ວີດີໂອ → skill `lao-football-video` ກັບ `voice: file:<ໄຟລ໌ນີ້>.mp3`.
6. **ສຽງ 2 ຄົນປ່ຽນກັນເວົ້າ** (ເຊັ່ນ ຈັນທີ + ໂຄ້ດບອລ): ໃສ່ `spk: ຈັນທີ` / `spk: ໂຄ້ດ` ທຸກແຖວໃນ script.md, ແລ້ວ
   `python3 video-studio/duo_voice.py video-studio/projects/<ຊື່>` → `voice.wav` (ສ້າງເປັນຊຸດ ~1500 ຕົວອັກສອນ/request, ເກັບ cache, ເລັ່ງ x1.25).
   ໂຄຕ້າຟຣີ 10 request/ມື້/ໂມເດລ → ໃຊ້ໂມເດລດຽວທັງເລື່ອງຖ້າເປັນໄປໄດ້ (`DUO_MODELS=gemini-3.8-flash-tts`).

## ໂຄງບົດຂອງແຕ່ລະສຽງ (≈ 30 ວິ ≈ 110–130 ຄຳ; 1 ນາທີ ≈ 230–260 ຄຳ)
- **1 (ດຸດັນ)** — Hook ແກ້ຄວາມເຂົ້າໃຈຜິດ `ຫຼາຍຄົນຄິດວ່າ..., ແຕ່ຄວາມຈິງແລ້ວ ...!` → ອະທິບາຍໂຊນ/ນາທີ/ຕຳແໜ່ງ ແຍກດ້ວຍ `,` → `—` ຜົນທີ່ຕັດສິນເກມ. ອ້າງນາທີ ຫຼື ໂຊນຈິງສະເໝີ; ບໍ່ໃຊ້ສັບອັງກິດຫຼາຍ.
- **2 (ກວນດີ)** — Hook ປຽບທຽບຊີວິດຄົນລາວ (`ວິ່ງໄວປານລົດຕຸກຕຸກລົງເປີ້ນ, ແຕ່ລືມເບກ!`) → ອາການແຟນບານວຸ້ນຂຶ້ນ → `—` ຕົບມຸກ → ແທັກໝູ່. ຫ້າມອະທິບາຍມຸກ.
- **3 (ຜູ້ຍິງ)** — ເປີດດ້ວຍຄຳອຸທານ `ໂອ້ຍທຸກຄົນ!` → ນາທີທີ່ລືມບໍ່ລົງ, ໃສ່ `,` ຕອນອາລົມປ່ຽນ → ເຫັນໃຈແຟນອີກຝ່າຍ → `—` ຖາມຄະແນນເຕັມສິບ.
- **4 (ກວນ)** — Hook ແຈ້ງເຕືອນ `ອອກມາແລ້ວລາຍຊື່ສິບເອັດຕົວຈິງ!` / `ອີກ...ຄູ່ເດືອດຈະເຂ່ຍບານແລ້ວ!` → 1–2 ຈຸດຫັກ (ບໍ່ອ່ານລາຍຊື່ຄົບ 11 ຄົນ) → `—` ຊວນທາຍຜົນ. ລາຍຊື່ຍັງບໍ່ອອກ → ຫ້າມເດົາ.
- **5 (ກວນຕີນ)** — Hook ກ່ອນເຕະ `ງ້າງຕີນຈາກສາມສິບຫຼາ!` → ເສັ້ນທາງບານ ແຍກດ້ວຍ `,` ດ້ວຍຄຳກິລິຍາແຮງ (ພຸ່ງໂຄ້ງ, ສຽບສາມຫຼ່ຽມ, ຕຸງຕາຂ່າຍ) → `—` ລະເບີດປິດທ້າຍ. ຄລິບ 14–22 ວິ ເໝາະສຸດ; ບໍ່ແຊກຂໍ້ມູນແທັກຕິກ.

## ກົດການຂຽນ (ທຸກສຽງ)
- **ຫ້າມໃຊ້ຄຳໄທ** ໃນບົດ ແລະ ໃນຄຳຕອບ: ບໍ່ໃຊ້ `ຄັບ`, `ຄ່ະ`, `ຄະ`, `ຖ້ວຍ` ແລະ ສຳນວນໄທ — ໃຊ້ພາສາລາວແທ້ (ເຊັ່ນ ເຈົ້າ, ເດີ້, ແດ່, ເນາະ).
- ຂຽນ **ແຊັ້ມ** (ບໍ່ແມ່ນ ແຊ້ມ / ຖ້ວຍ): `ແຊັ້ມ FA`, `ແຊັ້ມໂລກ`.
- **ຢ່າໃຫ້ຄືອ່ານ**: ຂຽນຄືຄົນທີ່ຮູ້ຈັກເລື່ອງແທ້ໆ ມາລົມເລົ່າ — ປະໂຫຍກສັ້ນ, ມີຄຳຖາມ-ຕອບ, ຈື່ຄວາມຫຼັງ (`ຈື່ໄດ້ບໍ່?`), ຄວາມຮູ້ສຶກສ່ວນຕົວ (`ສ່ວນຂ້ອຍ…`, `ໃນສາຍຕາຂ້ອຍ…`).
- **ຄວາມໄວ**: Joe ມັກໄວກວ່າຄ່າເລີ່ມຕົ້ນ 20–30%. ສຽງ 2 ຄົນ (`video-studio/duo_voice.py`) ເລັ່ງ x1.25 ໃຫ້ເອງ (`DUO_TEMPO`); ສຽງດ່ຽວ ໃຫ້ເລັ່ງດ້ວຍ `ffmpeg -af atempo=1.25`.
- **ຂຽນເປັນໂຕລາວທັງໝົດ** ລວມທັງຊື່ຄົນ/ທີມ/ສະໜາມ; **ຕົວເລກຂຽນເປັນຄຳ** (`ສາມຕໍ່ສອງ`, `ນາທີທີເຈັດສິບເຈັດ`, `ແປດສິບລ້ານ`).
- `,` = ຫາຍໃຈໄວ; `—` **ບ່ອນດຽວ** ກ່ອນຈຸດລະເບີດ/ມຸກ/ຄຳຖາມສຸດທ້າຍ.
- ບໍ່ເປີດແບບ "ສະບາຍດີທ່ານຜູ້ຊົມ"; ບໍ່ດູຖູກນັກເຕະເປັນສ່ວນຕົວ.

## ຂໍ້ຈຳກັດທີ່ຕ້ອງບອກຕາມຄວາມຈິງ
- Claude ຟັງສຽງບໍ່ໄດ້ → ຂໍໃຫ້ Joe ຟັງຄຳອ່ານຊື່ໃໝ່ທຸກເທື່ອ.
- ຕ້ອງມີ `python3` + `ffmpeg` ແລະ ອິນເຕີເນັດໄປ `generativelanguage.googleapis.com`.
- API key: cloud session ໃຊ້ Network secret ຂອງ `generativelanguage.googleapis.com` (header `x-goog-api-key`); ໃນຄອມ ໃຊ້ `GEMINI_API_KEY`. ຢ່າໃຫ້ Joe ວາງ key ໃນແຊັດ.
- ໂຄຕ້າຟຣີ ~10 ເທື່ອ/ມື້/ໂມເດລ. ໃຊ້ໂມເດລສຳຮອງ → ບອກ Joe ວ່ານ້ຳສຽງອາດຕ່າງຈາກຕົວຢ່າງໜ້ອຍໜຶ່ງ.
