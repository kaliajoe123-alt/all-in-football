# Spoken Lao: example bank and QA prompts

These are style anchors, not fixed phrases to copy. Use Lao wording that fits the user, age, setting, and intent. Avoid reproducing any single example mechanically.

## Rewrite pairs: too formal/translated -> natural spoken Lao

### 1. Opening a personal explanation
**Stiff:** `ໃນມື້ນີ້ ຂ້າພະເຈົ້າຈະດຳເນີນການນຳສະເໜີຂໍ້ມູນທີ່ສຳຄັນໃຫ້ທ່ານຮັບຊາບ.`
**Natural:** `ມື້ນີ້ມີເລື່ອງໜຶ່ງຢາກມາເລົ່າໃຫ້ຟັງ. ເລື່ອງນີ້ສຳຄັນຢູ່ເດີ.`
**Why:** Short thoughts; a genuine spoken opening, no artificial bureaucracy.

### 2. Ask a teammate to check stock
**Stiff:** `ກະລຸນາດຳເນີນການກວດສອບຈຳນວນສິນຄ້າໃນຄັງໃຫ້ຖືກຕ້ອງ.`
**Natural:** `ຊ່ວຍເຊັກສະຕັອກໃຫ້ແດ່ ວ່າຂອງຍັງເຫຼືອຈັກໂຕ ແລ້ວສົ່ງຕົວເລກມາໃຫ້ນຳ.`
**Why:** Clear action and next step; adjust unit word to actual product.

### 3. A customer inquiry
**Stiff:** `ທ່ານມີຄວາມປະສົງຈະຮັບຮູ້ລາຄາຂອງສິນຄ້າດັ່ງກ່າວຫຼືບໍ່?`
**Natural:** `ສົນໃຈຮຸ່ນໃດຢູ່? ສົ່ງຮູບຫຼືຊື່ຮຸ່ນມາໄດ້ເລີຍ ຂ້ອຍຊ່ວຍເຊັກລາຄາໃຫ້.`
**Why:** Helpful and natural, without implying a checked price is already known.

### 4. Football match tease
**Stiff:** `ຜົນການແຂ່ງຂັນດັ່ງກ່າວໄດ້ສ້າງຄວາມປະຫຼາດໃຈຢ່າງຫຼວງຫຼາຍ.`
**Natural:** `ເກມນີ້ຫັກມຸມແຮງເລີຍ! ຕອນທຳອິດຄິດວ່າຈະໄປອີກແບບ ແຕ່ພໍເກມປ່ຽນ... ທຸກຢ່າງກໍປ່ຽນຕາມ.`
**Why:** Spoken suspense. Only use when facts support a surprising game.

### 5. Match commentary at a near goal
**Stiff:** `ນັກເຕະໄດ້ດຳເນີນການຍິງລູກບານໄປຍັງປະຕູ.`
**Natural:** `ບານມາແລ້ວ... ມີຊ່ອງຍິງ! ຍິງ! ໂອ້ຍ ເກືອບເຂົ້າ!`
**Why:** Action first; tempo rises only at the decisive moment.

### 6. Cautious transfer coverage
**Stiff:** `ການຍ້າຍສະໂມສອນຂອງນັກເຕະຄົນນີ້ໄດ້ເກີດຂຶ້ນແລ້ວ.`
**Natural:** `ຕອນນີ້ມີຂ່າວວ່າລາວອາດຈະຍ້າຍທີມ. ແຕ່ຍັງບໍ່ມີການຢືນຢັນທາງການເດີ.`
**Why:** Crucial distinction: a report is not a completed transfer.

### 7. Natural two-person comedy
**A:** `ເອົານ້ຳແກ້ວໜຶ່ງແດ່.`
**B:** `ໄດ້. ເອົານ້ຳກ້ອນນຳບໍ່?`
**A:** `ເອົາ. ແຕ່ເອົາໜ້ອຍໆເດີ.`
**B:** `ໜ້ອຍປານໃດ?`
**A:** `ສອງກ້ອນພໍ... ມື້ນີ້ຂ້ອຍບໍ່ຢາກໄດ້ຫຍັງເກີນຈຳເປັນ.`
**Why:** Turns are responsive and distinctive. This is an example of rhythm, not necessarily a finished joke.

### 8. Friendly manager instruction
**Stiff:** `ຂໍໃຫ້ພະນັກງານທຸກຄົນດຳເນີນການນຳສົ່ງລາຍງານຕາມກຳນົດ.`
**Natural:** `ມື້ນີ້ຊ່ວຍສົ່ງລາຍງານໃຫ້ຄົບແດ່ເດີ. ຖ້າມີບັນຫາຈຸດໃດ ໃຫ້ແຈ້ງມາເລີຍ.`
**Why:** Firm yet approachable, with an explicit next action.

## Good patterns / problematic patterns

| Good | Problematic |
| --- | --- |
| Short connected ideas, changing sentence lengths | Every line the same length |
| One apt particle when needed | `ເດີ ເດີ ເດີ` in every turn |
| Lao core with familiar domain terms | Translated Thai idioms disguised as Lao |
| Pause for suspense at one turning point | Ellipses and exclamation marks in every sentence |
| Fact-check and preserve source caveats | Invented club news or claims for a punchy hook |
| Distinct character intentions | Both characters speak in the same narrator voice |

## Lightweight user tests

**Test A — Everyday rewrite:** `ປັບໃຫ້ເປັນພາສາເວົ້າ: ຂໍໃຫ້ທ່ານດຳເນີນການສົ່ງຮູບສິນຄ້າໃນມື້ນີ້.`
Expected: a natural concise request; no bureaucratic words.

**Test B — Football analysis:** `ຂຽນຄຳເວົ້າ 20 ວິນາທີ ວ່າທີມເສຍເພາະປ້ອງກັນບໍ່ດີ, ບໍ່ໃຫ້ແຕ່ງຜົນບານ.`
Expected: short rhythmic speech; no invented team or match result; useful analysis.

**Test C — Comedy dialogue:** `ຂຽນບົດລົມກັນສອງຄົນ ແບບລາວ ບໍ່ເອົາຜູ້ບັນຍາຍ.`
Expected: two distinct voices, short turns, no accidental third speaker.

**Test D — Business:** `ປັບໃຫ້ເປັນຂໍ້ຄວາມຜູ້ຈັດການເວົ້າກັບທີມ ແບບສຸພາບແຕ່ບໍ່ທາງການ.`
Expected: action-first respectful wording, no excessive jargon.
