# ພາກແບບກວນໆ (ອ້າຍບ່າວຂ້າງບ້ານ)

Joe ຂຽນພາສາລາວ — **ຕອບເປັນພາສາລາວ, ສັ້ນ**. ໃຫ້ພຽງ "ເກມ / ເລື່ອງ" ແລະ ຄວາມຍາວ ກໍ່ພໍ.

## ສຽງ (ຜ່ານການຮັບຮອງຈາກ Joe ແລ້ວ)
- **Voice**: `Puck` · **Model**: `gemini-3.8-flash-lite-tts` (ຖ້າໝົດໂຄຕ້າ → `gemini-3.8-flash-tts` → `gemini-3.1-flash-tts-preview`, ສະຄຣິບປ່ຽນໃຫ້ເອງ)
- **Style**: `Witty, clear, fast-talking Lao football banter creator. Rapid continuous comedic pacing with lively quick breath beats right before punchlines, energetic fan excitement.`
- ຕົວຢ່າງທີ່ Joe ໃຫ້ຜ່ານ: `references/example-mu-liverpool.md` (ແມນຢູ 3–2 ລີເວີພູ, 57 ວິ) — ໃຊ້ເປັນມາດຕະຖານນ້ຳສຽງ ແລະ ຈັງຫວະ.

## ຂັ້ນຕອນ
1. **ຄົ້ນຂໍ້ມູນ** (WebSearch 2–4 ແຫຼ່ງ): ຜົນ, ຜູ້ຍິງ + ນາທີ, ຈຸດຫັກຂອງເກມ, ຄວາມໝາຍ (ອັນດັບ, ໂຄຕ້າ UCL), ນັດຕໍ່ໄປ.
   ມຸກແມ່ນແຕ່ງໄດ້, **ຂໍ້ເທັດຈິງຫ້າມແຕ່ງ**. ແຫຼ່ງບໍ່ກົງກັນ (ເຊັ່ນ ນາທີ) → ເລືອກອັນໜຶ່ງ ແລ້ວບອກ Joe.
2. **ຂຽນບົດ** ເປັນ `.txt` ໃນ scratchpad (ໂຄງສ້າງລຸ່ມນີ້).
3. **ສ້າງສຽງ**:
   ```bash
   python3 <ໂຟນເດີ skill ນີ້>/scripts/tts.py <ບົດ.txt> <ຊື່>_Puck.mp3
   ```
   ສະຄຣິບບອກຄວາມຍາວ. ຫ່າງຈາກເປົ້າເກີນ ~10% → ເພີ່ມ/ຕັດປະໂຫຍກ ແລ້ວສ້າງໃໝ່ (ລະວັງ: ໂຄຕ້າຟຣີ ~10 ເທື່ອ/ມື້/ໂມເດລ).
4. **ສົ່ງ** MP3 ດ້ວຍ SendUserFile, ແລ້ວຕອບສັ້ນໆ: ຄວາມຍາວ, ໂມເດລທີ່ໃຊ້, ຂໍ້ເທັດຈິງທີ່ໃຊ້ + ແຫຼ່ງ, ສິ່ງທີ່ Joe ຕ້ອງຟັງກວດ (ຄຳອ່ານຊື່ນັກເຕະ).

## ໂຄງສ້າງບົດ
| ຄວາມຍາວ | ປະມານ | ໂຄງ |
|---|---|---|
| 15–25 ວິ | 1 ຈຸດຫັກ | Hook ປຽບທຽບ (0–3 ວິ) → ເລົ່າໃຫ້ວຸ້ນ + ອາການແຟນບານ → `—` ຕົບມຸກ + ແທັກໝູ່ |
| ~30 ວິ | ≈ 120–130 ຄຳ | ຄືກັນ, ເພີ່ມອາການແຟນ 2–3 ພາບ |
| ~1 ນາທີ | ≈ 230–260 ຄຳ | Hook → ເລົ່າເກມຕາມລຳດັບປະຕູ (ແຕ່ລະປະຕູມີມຸກ/ອາການແຟນ) → ຈຸດຫັກ → `—` ຕົບມຸກ → ແທັກໝູ່ + ນັດຕໍ່ໄປ |

**ສູດ Hook 3 ວິ:**
1. `ກອງຫຼັງຄົນນີ້ວິ່ງໄວປານ..., ແຕ່ລືມ...!` — ປຽບທຽບຊີວິດປະຈຳວັນຄົນລາວ
2. `ໃຜເປັນແຟນທີມນີ້ ກຽມຢາດົມໄວ້ຂ້າງໂຕເລີຍ!` — ເວົ້າເກີນຈິງເລື່ອງຄວາມເຈັບຂອງແຟນ
3. `ປະຕູກວ້າງເທົ່າບ້ານ ແຕ່ຍິງອອກໄປໃສກໍບໍ່ຮູ້!` — ຍົກຈຸດພາດທັນທີ

**ຄັງມຸກລາວ** (ໃຊ້ຊ້ຳໄດ້, ຄິດໃໝ່ຍິ່ງດີ): ລົດຕຸກຕຸກລົງເປີ້ນລືມເບກ · ກາເຟຍັງບໍ່ທັນເຢັນ · ປິດໂທລະທັດໄປນອນ / ລຸກມາເປີດຄືນຕາຍັງບໍ່ມືນ ·
ຫົວໃຈເຕັ້ນແຮງກວ່າລຳໂພງງານບຸນບ້ານ · ຖິ້ມຂີ້ເຫຍື້ອໜ້າເຮືອນຄົນອື່ນ ລົມພັດກັບຄືນ · ຍ່າງເຂົ້າປະຕູຄືຍ່າງໄປຕະຫຼາດເຊົ້າ · ລຸງຮ້ານກາເຟ · ຢາດົມ.

## ກົດການຂຽນ (ໃຫ້ສຽງອອກມາດີ)
- **ຂັດເກົາບົດດ້ວຍ skill `natural-spoken-lao`** ກ່ອນສ້າງສຽງ: ພາສາເວົ້າແບບຄົນລາວລົມກັນ, ຈັງຫວະມີຂຶ້ນມີລົງ, ຂໍ້ເທັດຈິງຄືເດີມ. ກົດໃນ skill ນີ້ (ຂຽນຊື່/ຕົວເລກເປັນໂຕລາວ, `—` ບ່ອນດຽວ) ຍັງໃຊ້ຄືເກົ່າ.
- **ຂຽນເປັນໂຕລາວທັງໝົດ**, ລວມທັງຊື່ຄົນ/ທີມ/ສະໜາມ (ເຊັ່ນ ຄູນຢາ, ເຊັສໂກ, ເມນູ, ໂຊບົສໄລ, ກັກໂປ, ແມັກ ອາລິສເຕີ, ໂອລ ແທຣັຟເຟີດ, ແອນຟິວ).
- **ຕົວເລກຂຽນເປັນຄຳ**: `ສາມຕໍ່ສອງ`, `ນາທີທີເຈັດສິບເຈັດ`, `ວັນທີຊາວເອັດ ພະຈິກ`.
- ໃສ່ `,` ລະຫວ່າງພາບ/ເຫດການ ໃຫ້ຫາຍໃຈໄວໆ; ໃສ່ `—` **ບ່ອນດຽວ** ກ່ອນມຸກສຸດທ້າຍ ເພື່ອໃຫ້ຢຸດກ່ອນຕົບ.
- ສຽງແບບເພື່ອນເວົ້າກັນ (ເດີ້, ເລີຍ, ແດ່, ປັ໊ບ) — ບໍ່ໃຊ້ພາສາຜູ້ປະກາດຂ່າວ, ບໍ່ເປີດດ້ວຍ "ສະບາຍດີທ່ານຜູ້ຊົມ".
- **ຫ້າມອະທິບາຍມຸກຫຼັງຕົບ**; ຈົບທັນທີດ້ວຍການແທັກໝູ່ / ນັດຕໍ່ໄປ.
- ກວນທີມ ແລະ ເກມ, ບໍ່ດູຖູກຕົວຄົນ (ເຊື້ອຊາດ, ຮູບຮ່າງ, ຄອບຄົວ) ແລະ ບໍ່ເຍາະເຍີ້ຍການບາດເຈັບ.

## ຂໍ້ຈຳກັດທີ່ຕ້ອງບອກຕາມຄວາມຈິງ
- ຕ້ອງມີ `python3` ແລະ `ffmpeg` ໃນເຄື່ອງ, ແລະ ອິນເຕີເນັດອອກໄປ `generativelanguage.googleapis.com` ໄດ້.
- Claude ຟັງສຽງບໍ່ໄດ້ → ຂໍໃຫ້ Joe ຟັງຄຳອ່ານຊື່ນັກເຕະໃໝ່ ແລ້ວເພີ່ມຄຳສະກົດທີ່ຖືກໃສ່ຄັງມຸກ/ຕົວຢ່າງ.
- API key: ໃນ cloud session ໃຊ້ Network secret ຂອງ `generativelanguage.googleapis.com` (header `x-goog-api-key`); ໃນຄອມ ໃຊ້ `GEMINI_API_KEY`.
  ບໍ່ມີ key → ບອກວິທີໃສ່ ແລະ ຢ່າໃຫ້ວາງ key ໃນແຊັດ.
- ໂຄຕ້າຟຣີ ~10 ເທື່ອ/ມື້/ໂມເດລ. ໝົດທຸກໂມເດລ → ບອກ Joe (ລໍມື້ໃໝ່ ຫຼື ເປີດ billing).
- ຢາກເອົາໄປໃສ່ວີດີໂອ: ໃຊ້ skill `lao-football-video` ກັບ `voice: file:<ໄຟລ໌ນີ້>.mp3`.
- ເມື່ອ Joe ຂໍ "ຄລິບ" ຫຼື "ວີດີໂອ" ໂດຍບໍ່ລະບຸສຽງ: **ຖາມທຸກຄັ້ງວ່າໃຊ້ສຽງໃຜ** (pak-kuan / chanthy-fans / ສຽງອັດເອງ) ກ່ອນສ້າງສຽງ.
