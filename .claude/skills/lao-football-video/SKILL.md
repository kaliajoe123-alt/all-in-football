# ວີດີໂອເຕະບານພາສາລາວ ແບບອັດຕະໂນມັດ (Lao Football Video Studio)

Joe ຂຽນພາສາລາວ — **ຕອບເປັນພາສາລາວ, ສັ້ນ**. ລາວໃຫ້ພຽງ "ຫົວຂໍ້" ກໍ່ພໍ; ທຸກຂັ້ນຕອນທີ່ເຫຼືອ skill ນີ້ເຮັດເອງ.

ຮູບແບບຖອດມາຈາກຄລິບວິເຄາະເຕະບານທີ່ Joe ສົ່ງເປັນຕົວຢ່າງ (ພື້ນເຈ້ຍ, ຮູບໃນກາດ, ປ້າຍຊື່ເຫຼືອງ, ກາດສະຖິຕິ,
ບົດແບ່ງເປັນຕອນ, ສຽງພາກນຳເລື່ອງ) ແລ້ວປັບໃຫ້ດີຂຶ້ນສຳລັບພາສາລາວ. ລາຍລະອຽດ: `references/style-guide.md`.

## ສາຍການຜະລິດ (ຄຳສັ່ງດຽວ)

```
ຫົວຂໍ້ → ① ຄົ້ນຂໍ້ມູນ → ② ຂຽນບົດ script.md → ③ ກວດ → ④ ຫາ footage + ສຽງພາກ (plan) → ⑤ ກວດຮູບ
       → ⑥ render (ຕັດຕໍ່ + ສຽງ) → ⑦ ກວດ QA → ⑧ ສົ່ງ MP4 + ໜ້າປົກ + caption
```

ຂັ້ນ ①② ແມ່ນ Claude ເຮັດ; ຂັ້ນ ③–⑧ ແມ່ນໂຄດ `scripts/laostudio` (Python + ffmpeg) ເຮັດທັງໝົດ.

```bash
bash .claude/skills/lao-football-video/scripts/setup.sh --vox    # ເທື່ອທຳອິດຂອງແຕ່ລະ session (5–10 ນາທີ: ສຽງພາກ VoxCPM2)
S=video-studio/studio                                            # ຕົວເອີ້ນໃຊ້
$S new   video-studio/projects/<NNN_ຊື່>  --title "ຫົວຂໍ້ *ຄຳສຳຄັນ*"
$S check video-studio/projects/<NNN_ຊື່>                         # ກວດບົດ
$S plan  video-studio/projects/<NNN_ຊື່>                         # ສຽງພາກ + footage + ແຜ່ນກວດຮູບ (ບໍ່ render)
$S run   video-studio/projects/<NNN_ຊື່> [--aspect 9:16 | --both] # ວີດີໂອສຳເລັດຮູບ
```

ຖ້າ skill ຖືກຕິດຕັ້ງນອກ repo ນີ້: `PYTHONPATH=<skill>/scripts python3 -m laostudio …`.

## ຖາມກ່ອນ (ເທື່ອດຽວ, ດ້ວຍ AskUserQuestion) — ສະເພາະສິ່ງທີ່ຍັງບໍ່ຮູ້

1. **ລາຍການໃດ?** (ປ້າຍມຸມຊ້າຍເທິງ `show:`) — ເກມເດືອດ · ALL IN ບານປາຍບູ້ງເກມ · ຝອຍນອກເກມ · ເລື່ອງໃນເດີ່ນຫຍ້າ (ສະກົດ **ຝອຍນອກເກມ** ສະເໝີ).
2. **ສຽງພາກ?** — ສຽງ AI ນັກເລົ່າ (`studio voices`): ຊາຍ `vox:mun` ມັນ ຕື່ນເຕັ້ນ (ຄ່າເລີ່ມຕົ້ນ) · `vox:ai` ອ້າຍເລົ່າເກັ່ງ · `vox:saeo` ແຊວ ຕະຫຼົກ; ຍິງ `vox:euay` ເລົ່າມ່ວນ · `vox:sing` ມັນ ຕື່ນເຕັ້ນ; ຫຼື ອັດສຽງເອງ (`voice: file:…`). ຖາມສະເພາະເມື່ອ Joe ຍັງບໍ່ໄດ້ເລືອກສຽງປະຈຳ.
3. **ຮູບແບບ?** — 16:9 (YouTube/Facebook) · 9:16 (TikTok/Reels) · ທັງສອງ (`--both`).

ຖ້າ Joe ບອກວ່າ "ເຮັດເລີຍ" ຫຼື ບໍ່ຢູ່: ໃຊ້ຄ່າເລີ່ມຕົ້ນ (ລາຍການຫຼ້າສຸດທີ່ໃຊ້, `vox:mun`, 16:9) ແລ້ວບອກວ່າເລືອກຫຍັງ.

## ① ຄົ້ນຂໍ້ມູນ
- ຄົ້ນເວັບ (WebSearch) 3–6 ແຫຼ່ງ: ຂ່າວ, ສະຖິຕິ (FBref, Transfermarkt, Opta, ເວັບລີກ), ຄຳເວົ້າຂອງຄົນໃນເລື່ອງ.
- **ທຸກຕົວເລກ/ຄຳເວົ້າ ຕ້ອງມີແຫຼ່ງ** → ໃສ່ `src:` ໃນແຖວນັ້ນ. ບໍ່ແນ່ໃຈ = ບໍ່ໃສ່ ຫຼື ເວົ້າກວ້າງໆ. ຫ້າມແຕ່ງຄຳເວົ້າ (quote) ຂຶ້ນເອງ.
- ຈົດ 5–8 "ຈຸດເລົ່າ" ກ່ອນຂຽນ: ປົມ → ທີ່ມາ → ຫຼັກຖານ → ຈຸດຫັກ → ບົດສະຫຼຸບ.

## ② ຂຽນບົດ `script.md`
**ອ່ານ `references/narration.md` ກ່ອນຂຽນທຸກເທື່ອ** (ຫຼັກການພາກ 10 ຂໍ້ຂອງ Joe: hook, ອາລົມ, dynamics, ຈັງຫວະ, ການເລົ່າເລື່ອງ, ຄວາມລຸ້ນ, ພາສາເວົ້າ, ຄວາມຮູ້ບານ, ມຸກ, ການສະແດງສຽງ)
ແລະ `references/script-format.md` (ຄຳສັ່ງທັງໝົດ + ຕົວຢ່າງ). ສະຫຼຸບ:
- **ເລົ່າ ບໍ່ແມ່ນອ່ານຂ່າວ.** ພາສາເວົ້າແບບຄົນລາວລົມກັນ (ເດີ, ຫວາ, ເລີຍ, ພີ່ນ້ອງ...), ບໍ່ໃຊ້ຄຳພາສາຂຽນ (ເຊິ່ງ, ດັ່ງນັ້ນ, ຢ່າງ...).
- **ທຸກແຖວມີ `emo:`** (hook, story, suspense, climax, calm, funny, angry, sad, happy, question) ແລະ ໃສ່ `...` ບ່ອນທີ່ຕ້ອງຢຸດ. ບໍ່ໃຫ້ອາລົມດຽວກັນເກີນ 3 ແຖວຕິດ.
- ໂຄງເລື່ອງ: **hook 3–5 ວິ** → ປົມບັນຫາ → ຄວາມຂັດແຍ່ງ → ສ້າງຄວາມລຸ້ນ → ຈຸດພິກຜັນ/climax → ມຸກ → ປິດແບບມີຄວາມໝາຍ + ຄຳຖາມໃຫ້ຄອມເມັ້ນ. ແບ່ງເປັນ 3–5 ບົດ (`# ຫົວຂໍ້ບົດ`).
- ປະໂຫຍກລະແຖວ, 6–16 ຄຳ. ປົນສັ້ນ-ຍາວ. **ຢ່າງໜ້ອຍ 90 ວິ** (~18–20 ແຖວ).
- ທຸກແຖວມີພາບ: `[emo: suspense | img: ຄຳຄົ້ນອັງກິດ | label: ຊື່ | stat: 52.6% = ຄຳອະທິບາຍ | src: ແຫຼ່ງ] ຂໍ້ຄວາມພາກ *ຄຳສຳຄັນ*`.
- **ຊື່ຕ່າງປະເທດອ່ານແບບລາວ** (Joe ສັ່ງ): ຂຽນໂຕລາຕິນໃນຂໍ້ຄວາມ ແລ້ວໃສ່ຄຳອ່ານລາວໃນ `say:` — `check` ບອກຄຳທີ່ຂາດ.
- ຕົວເລກຂຽນເປັນເລກ (`2.21`, `35`, `2-1`, `74%`) — ລະບົບອ່ານເປັນຄຳລາວເອງ.

## ③–⑤ ກວດ, ວາງແຜນ, ກວດຮູບ
- `check` ຕ້ອງ "ຜ່ານ ✓". ຈາກນັ້ນ `plan` → ເປີດເບິ່ງ `out/<ຊື່>_footage.jpg` (ຮູບທຸກຊັອດມີເລກ) ແລະ `_plan.json` (ຊື່ໄຟລ໌ທີ່ເລືອກ).
- **ກວດວ່າຮູບຄົນຖືກຄົນ** ໂດຍເບິ່ງຊື່ໄຟລ໌ໃນ `_plan.json` (ປ້າຍ `label:` ຕ້ອງກົງກັບຄົນໃນຮູບ). ຮູບບໍ່ກົງ → ປ່ຽນຄຳຄົ້ນ (ເພີ່ມທີມ/ປີ/ຕຳແໜ່ງ), ເລືອກອັນດັບອື່ນ `ຄຳຄົ້ນ #2`, ຫຼື ວາງໄຟລ໌ຂອງ Joe ໃນ `assets/`. ແລ່ນ `plan` ຊ້ຳຈົນດີ (ຜົນຄົ້ນຖືກ cache, ບໍ່ໂຫຼດຊ້ຳ).
- ລາຍລະອຽດແຫຼ່ງ footage ແລະ ລິຂະສິດ: `references/footage.md`.

## ⑥ Render
`run` ເຮັດ: ສຽງພາກ → timeline (ຕັດທຸກ ~3.5 ວິ ຕາມຈັງຫວະຄຳ) → ພາບ (render ຂະໜານ) → ເພງ+ເອັບເຟັກ+ຜະສົມ -14 LUFS → MP4.
ສຽງ `vox` ສັງເຄາະຊ້າເທິງ CPU (~4–5 ວິ ຕໍ່ສຽງ 1 ວິ + ໂຫຼດໂມເດລ ~1–3 ນາທີ): ຄລິບ 2 ນາທີ ≈ 10–12 ນາທີ, 10 ນາທີ ≈ 50 ນາທີ; ພາບ render ອີກ ~1 ນາທີ ຕໍ່ວີດີໂອ 1 ນາທີ.
ທຸກປະໂຫຍກຖືກ cache → ແກ້ບົດແລ້ວ run ໃໝ່ ຈະສັງເຄາະສະເພາະແຖວທີ່ປ່ຽນ. ແລ່ນ background, ຢ່າແລ່ນຊ້ອນກັນສອງເທື່ອໃນໂປຣເຈັກດຽວ.
ສຽງ ແລະ ເພງ: `references/voice-sound.md`.

## ⑦ QA ກ່ອນສົ່ງ (ບັງຄັບ)
ເປີດເບິ່ງ `out/<ຊື່>_qa.jpg` (ແຜ່ນລວມຈຸດສຳຄັນ) ແລະ `_report.json`:
- ຫົວຂໍ້ hook ຢູ່ໃນຈໍ, ຄຳສຳຄັນເປັນສີ; ສະຫຼະ/ວັນນະຍຸດລາວບໍ່ຊ້ອນຜິດ; ບໍ່ມີກ່ອງ □.
- ປ້າຍຊື່ກົງກັບຄົນ; ກາດສະຖິຕິບໍ່ບັງໜ້າ; ຄຳບັນຍາຍບໍ່ລົ້ນ; ໂລໂກ້ + ປ້າຍລາຍການຄົບ.
- `placeholders: 0` ແລະ `missing_footage: []` (ຖ້າບໍ່ → ແກ້ຄຳຄົ້ນ ຫຼື ຂໍຮູບຈາກ Joe).
- ຄວາມຍາວ ≥ 90 ວິ; ຖ້າໃຊ້ສຽງອັດ: `voice_removed_pauses` ບອກວ່າຕັດຊ່ວງງຽບອອກເທົ່າໃດ.
ແກ້ `script.md` ແລ້ວ `run` ໃໝ່ (ສຽງ ແລະ ຮູບຖືກ cache → ໄວ).

## ⑧ ສົ່ງ
ໄຟລ໌ຢູ່ `video-studio/projects/<ຊື່>/out/`: `<ຊື່>.mp4` · `_cover.jpg` · `_caption.txt` (ຂໍ້ຄວາມໂພສ + hashtag + ເຄຣດິດຮູບ) · `.srt` ·

(ຕົວເລກ, ຊື່ລາຍການ), ແລະ ຂໍ້ຈຳກັດ (ເຊັ່ນ ສຽງ AI ເປັນຮ່າງ). ຢ່າລຶບໄຟລ໌ເກົ່າ. ຢ່າ commit ວີດີໂອ (`out/` ຖືກ ignore); commit ສະເພາະ `script.md` ແລະ `assets/` ທີ່ນ້ອຍ.

- **ຄຳບັນຍາຍເທົ່າທີ່ຈຳເປັນ** (Joe ສັ່ງ): ຄ່າເລີ່ມຕົ້ນ `captions: key` = ຂຶ້ນສະເພາະວັກ `*ຄຳສຳຄັນ*` ຕອນທີ່ເວົ້າເຖິງ (ສີແດງ). ຢ່າໃສ່ດາວເກີນ 1 ວັກສັ້ນຕໍ່ແຖວ; ແຖວທີ່ບໍ່ຈຳເປັນບໍ່ຕ້ອງໃສ່. `captions: full` (ທຸກຄຳ) ໃຊ້ສະເພາະເມື່ອ Joe ຂໍ.
- **ສຽງພາກ** (Joe ສັ່ງ): ຕ້ອງດຶງດູດ ຟັງຈົນຈົບ — ສະແດງອາລົມ, ມີສູງ-ຕ່ຳ ໜັກ-ເບົາ, ຈັງຫວະໄວ-ຊ້າ ແລະ ການຢຸດ; ສຽງແຈ້ງ ຊັດ; **ບໍ່ເອົາສຽງທຸ້ມ, ບໍ່ເອົາແບບອ່ານຂ່າວ**; ຊື່ອັງກິດອ່ານແບບລາວ; ສຽງດຽວກັນທຸກຄລິບ. ຄ່າເລີ່ມຕົ້ນ `vox:mun`. ຫົວຂໍ້ hook ມີຄຳເນັ້ນສະເໝີ (`*…*`).
- ສຽງພາກຢູ່ເທິງ, ເພງເບົາ ແລະ ຫຼົບໃຫ້ສຽງພາກ; ລະດັບລວມ -14 LUFS.
- 3 ວິສຸດທ້າຍ: ໂລໂກ້ + ປຸ່ມ "ກົດຕິດຕາມ" + ຂໍ້ຄວາມ `cta`.
- 9:16: ເນື້ອຫາສຳຄັນຢູ່ລະຫວ່າງ 12%–72% ຂອງຄວາມສູງ (ຫຼົບປຸ່ມຂອງ TikTok/Reels).
- ພາບແມັດຖ່າຍທອດສົດ/ຮູບສຳນັກຂ່າວ ອາດຖືກປິດສຽງ ຫຼື ລຶບ → ໃຊ້ຮູບລິຂະສິດເສລີ ຫຼື ຂອງ Joe ເອງ; ບອກ Joe ເທື່ອດຽວຖ້າລາວສົ່ງພາບແບບນັ້ນມາ.
- ແບຣນ: `assets/brand/allin.json` (ສີ, ຊື່, handle, ໂລໂກ້ `allin_logo.png` — ຖ້າບໍ່ມີໄຟລ໌ໂລໂກ້ ຈະແຕ້ມປ້າຍ "ALL IN" ແທນ). ທຸລະກິດອື່ນ: ສຳເນົາເປັນ `<ຊື່>.json` ແລ້ວໃສ່ `brand: <ຊື່>` ຫຼື ວາງ `brand.json` ໃນໂປຣເຈັກ.

## ເຮັດອັດຕະໂນມັດຕາມເວລາ
ເມື່ອ Joe ຢາກໄດ້ຄລິບປະຈຳ (ເຊັ່ນ ທຸກເຊົ້າ: "ສະຫຼຸບຜົນບານຄືນນີ້") ໃຫ້ຕັ້ງ scheduled task ທີ່ເປີດ session ໃໝ່ໃນ repo ນີ້ ພ້ອມຄຳສັ່ງ:
"ໃຊ້ skill lao-football-video ເຮັດວີດີໂອເລື່ອງ <ຫົວຂໍ້/ກົດເລືອກຫົວຂໍ້>, 9:16, ສຽງ mms, ແລ້ວສົ່ງໄຟລ໌".
ຖາມ Joe ກ່ອນວ່າ ເວລາໃດ, ຖີ່ປານໃດ, ຫົວຂໍ້ແນວໃດ — ຢ່າຕັ້ງເອງ.

## ຂໍ້ຈຳກັດທີ່ຕ້ອງບອກຕາມຄວາມຈິງ
- ສຽງ `vox:*` ເປັນສຽງ AI ທີ່ອອກແບບຂຶ້ນ (ບໍ່ແມ່ນສຽງຄົນຈິງ), 48 kHz, ໃຊ້ທາງການຄ້າໄດ້ (Apache-2.0); ຄວນບອກຜູ້ຊົມວ່າເປັນສຽງ AI. ບາງຄັ້ງອ່ານຄຳຜິດ ຫຼື ຂ້າມຄຳ → ຖ້າ Joe ແຈ້ງແຖວທີ່ຜິດ ໃຫ້ແກ້ຄຳສະກົດ/`say:` ຂອງແຖວນັ້ນ ແລ້ວ run ໃໝ່.
- ສຽງ `mms` ເປັນສຽງ 16 kHz (ຟັງຮູ້ວ່າ AI), ລິຂະສິດ CC BY-NC → ໃຊ້ເປັນຮ່າງໄວເທົ່ານັ້ນ.
- Claude ຟັງສຽງບໍ່ໄດ້: ກວດໄດ້ພຽງລະດັບສຽງ (Hz) ແລະ ຖອດສຽງກັບຄືນເປັນໂຕໜັງສື → ຂໍ Joe ຟັງຢືນຢັນສຽງ ແລະ ຄຳອ່ານຊື່ໃໝ່.
- ຫ້າມສ້າງ voice card ຈາກສຽງຄົນອື່ນ; `voice-add` ໃຊ້ໄດ້ກັບສຽງຂອງເຈົ້າຂອງເອງ (Joe, ທອງດຳ) ທີ່ຍິນຍອມເທົ່ານັ້ນ.
