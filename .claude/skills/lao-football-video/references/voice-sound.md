## ສຽງພາກ (`voice:`)

### ສຽງ AI ທີ່ມີໃຫ້ (`studio voices`)
ຄຸນສົມບັດທີ່ Joe ຕ້ອງການ: **ສຽງແຈ້ງ, ຊັດທຸກພະຍາງ, ມີຂຶ້ນມີລົງ, ຄືລົມກັບໝູ່, ໄວພໍດີ, ອ່ານອັງກິດຄ່ອງ — ບໍ່ເອົາສຽງທຸ້ມ.**

| ຊື່ | ເພດ | ລັກສະນະ |
|---|---|---|
| `vox:chaeng` | ຊາຍ | ສຽງແຈ້ງ ຊັດທຸກພະຍາງ — ນັກວິເຄາະບານ (**ຄ່າເລີ່ມຕົ້ນ**) |
| `vox:khao` | ຊາຍ | ສຽງແຈ້ງ ໝັ້ນໃຈ — ຜູ້ປະກາດຂ່າວກິລາ |
| `vox:vai` | ຊາຍ | ໜຸ່ມ ສົດໃສ ມີຊີວິດຊີວາ — ນັກເລົ່າເລື່ອງ |

| `vox:sao` | ຍິງ | ສົດໃສ ໝັ້ນໃຈ — ຜູ້ປະກາດຂ່າວກິລາ |
ລະດັບສຽງທີ່ວັດໄດ້ຂອງແຕ່ລະສຽງຢູ່ໃນ `card.json` (`f0_hz`). ສຽງທຸ້ມ (thum, khem, nang) ຖືກຖອດອອກຕາມຄຳສັ່ງຂອງ Joe.

### ຄຳພາສາອັງກິດ
ສຽງ `vox` ເວົ້າໄດ້ສອງພາສາ: ຄຳໂຕລາຕິນໃນບົດ **ຖືກອ່ານເປັນອັງກິດແທ້** (ບໍ່ຕ້ອງສະກົດເປັນລາວ) — ຜົນຄືຄົນລາວທີ່ເວົ້າອັງກິດຄ່ອງ.
- ສະກົດຊື່ໃຫ້ຖືກຕາມອັງກິດ; ໃຊ້ຊື່ເຕັມ (Manchester City, Premier League).
- ຖ້າຊື່ໃດອ່ານຜິດ ໃຫ້ໃສ່ການສະກົດຕາມສຽງເປັນ **ໂຕລາຕິນ** ໃນ `say:` (ເຊັ່ນ `Neuer: Noy-er`, `Guardiola: Gwar-dee-oh-la`). ຄ່າ `say:` ທີ່ເປັນໂຕລາວຈະບໍ່ຖືກໃຊ້ກັບ `vox`.
- ຢາກໃຫ້ອ່ານຊື່ແບບສຳນຽງລາວ (ສະກົດລາວ) ຄືເກົ່າ: ໃສ່ `english: lao` ໃນສ່ວນຫົວ ແລ້ວໃຫ້ຄຳອ່ານລາວໃນ `say:`.
- ສຽງ `mms` ອ່ານອັງກິດບໍ່ໄດ້ → ຍັງຕ້ອງມີຄຳອ່ານລາວໃນ `say:` ສະເໝີ.

Voice card ຢູ່ `assets/voices/<ຊື່>/` (`ref.wav` + `card.json`). ໂປຣເຈັກມີ `voices/` ຂອງຕົນເອງໄດ້.

```bash
studio voices                                         # ລາຍຊື່
studio voice-test --voices chaeng,sai --out samples    # ຟັງທຽບ (mp3)
studio voice-design <ຊື່> --gender ຊາຍ --label "…" --desc "A man in his early thirties with a clear, bright, clean mid-pitched voice. Very crisp and precise articulation. Energetic, friendly football analyst, fluent in English"
studio voice-add joe --wav joe_10s.wav --text "ຂໍ້ຄວາມທີ່ເວົ້າໃນຄລິບ"   # ສຽງຂອງເຈົ້າຂອງເອງເທົ່ານັ້ນ
```
- `--desc` ຂຽນພາສາອັງກິດ: ເພດ, ອາຍຸ, ລະດັບສຽງ (low-pitched / deep / bright), ນ້ຳສຽງ, ຈັງຫວະ.
- ຜົນຂອງ voice design **ບໍ່ຄືກັນທຸກຮອບ** ແລະ ມັກອອກສູງກວ່າທີ່ຂຽນ: ສ້າງ 3–4 ຮອບ, ວັດ F0 (ຊາຍທຸ້ມ 100–125 Hz, ຍິງທຸ້ມ 180–205 Hz),
  ເລືອກອັນທີ່ຢູ່ໃນຊ່ວງ ແລະ ມີພະລັງງານຄວາມຖີ່ສູງ (>3 kHz) ຫຼາຍສຸດ = ຟັງແຈ້ງ ຊັດ. ຊາຍສຽງແຈ້ງ 135–170 Hz, ຍິງ 205–250 Hz.
  ປັບລະດັບສຽງຂອງ `ref.wav` ໄດ້ບໍ່ເກີນ ~2.5 semitone ດ້ວຍ `ffmpeg -af rubberband=pitch=1.06:formant=preserved`.
- ເມື່ອ Joe ເລືອກສຽງປະຈຳແລ້ວ ໃຫ້ໃຊ້ສຽງນັ້ນທຸກຄລິບ (ຕົວຕົນຂອງຊ່ອງ).
- ເວລາຂອງຄຳ (ສຳລັບຄຳບັນຍາຍ) ຄິດຈາກຄວາມຍາວຈິງຂອງປະໂຫຍກ ແບ່ງຕາມສັດສ່ວນຄວາມຍາວພະຍາງ → ກົງປະມານ ±0.3 ວິ.
- ຖ້າປະໂຫຍກໃດອອກມາສັ້ນ/ຍາວຜິດປົກກະຕິ (ຂ້າມຄຳ ຫຼື ເວົ້າຊ້ຳ) ໃຫ້ລຶບ cache ຂອງມັນໃນ `.cache/voice/` ແລ້ວ run ໃໝ່.

### ຂັ້ນຕອນເມື່ອ Joe ອັດສຽງເອງ
1. ຂຽນ `script.md` ໃຫ້ຈົບ → ສົ່ງຂໍ້ຄວາມພາກ (ບໍ່ມີ `[…]`) ໃຫ້ Joe ອ່ານຕາມລຳດັບ ແຖວຕໍ່ແຖວ.
2. ວາງໄຟລ໌ສຽງໃນໂປຣເຈັກ, ຕັ້ງ `voice: "file:ຊື່ໄຟລ໌"`.
3. ລະບົບຈະ: ຕັດຊ່ວງງຽບທີ່ຍາວກວ່າ 0.35 ວິ ອອກ (`tighten: false` ເພື່ອປິດ), ຫາຈຸດຢຸດຫາຍໃຈ, ແລ້ວຈັບຄູ່ປະໂຫຍກກັບສຽງ
   (ແຕ່ລະປະໂຫຍກໄດ້ເວລາຕາມສັດສ່ວນຄວາມຍາວ ແລະ ຕັດຕົງຈຸດຢຸດ). ຄຳບັນຍາຍຈຶ່ງກົງລະດັບປະໂຫຍກ; ພາຍໃນປະໂຫຍກແມ່ນປະມານ.
4. Joe ຕ້ອງອ່ານ **ຕາມບົດ ບໍ່ຂ້າມ ບໍ່ສະຫຼັບແຖວ**. ຖ້າອ່ານຜິດແລ້ວອ່ານຄືນ → ຕັດສ່ວນຜິດອອກກ່ອນ ຫຼື ແກ້ບົດໃຫ້ກົງ.
5. ສຽງອັດ: ກາດ "ບົດທີ N" ຖືກປິດ (ບໍ່ມີຊ່ອງງຽບໃຫ້ແຊກ) — ຊື່ບົດຂຶ້ນເປັນປ້າຍມຸມຊ້າຍເທິງແທນ.

### ຄຳອ່ານ (`say:`) ສຳລັບສຽງ `mms` ຫຼື `english: lao`
- ໃນໂໝດນີ້ລະບົບສົ່ງໃຫ້ສຽງ AI ສະເພາະໂຕລາວ (ຊື່ຕ່າງປະເທດອ່ານຕາມສຳນຽງລາວ). ທຸກຄຳໂຕລາຕິນຕ້ອງມີຄຳອ່ານ; `check` ບອກຄຳທີ່ຂາດ.
- ຕົວເລກ, ເປີເຊັນ, ຜົນການແຂ່ງຂັນ, `ໆ` → ລະບົບແປງເອງ (`2014` → ສອງພັນສິບສີ່, `2-1` → ສອງ ຕໍ່ ໜຶ່ງ, `52.6%` → ຫ້າສິບສອງຈຸດຫົກ ເປີເຊັນ).
- ຄຳອ່ານຍາກ ໃຫ້ແຍກພະຍາງ ແລະ ທົດລອງ 2–3 ແບບ; Claude ຟັງສຽງບໍ່ໄດ້ → ຂໍ Joe ຟັງຢືນຢັນ ແລ້ວເກັບຄຳອ່ານທີ່ຖືກໄວ້ໃຊ້ຕໍ່.
- ຢາກໃຫ້ຢຸດຫາຍໃຈ: ໃສ່ຈຸດ `,` ຫຼື ຍະຫວ່າງ. `speed:` ປັບຄວາມໄວ.

## ເພງ (`music:`)
ລຳດັບ: `music.*` ໃນໂປຣເຈັກ → ທີ່ຢູ່ໄຟລ໌ໃນ `music:` → ຄັງ `<library>/MUSIC/<ເດືອດ|ລຸ້ນ|ເສົ້າ|ມ່ວນ>/` → **ເພງສັງເຄາະ** (pad + bass ເບົາໆ, ບໍ່ມີລິຂະສິດ).
ຄັງ: ຕັ້ງ `LAOSTUDIO_LIBRARY=/path/ຄັງ` ຫຼື `"library": ["/path"]` ໃນ brand json. ຄັງຂອງ Joe ຢູ່ Dropbox `1. ALL IN/marketing/` (ໂຟນເດີ `MUSIC/`, `SFX/`).
ເພງສັງເຄາະເປັນພຽງພື້ນ; ຖ້າ Joe ຢາກໄດ້ເພງດັງ ໃຫ້ໃສ່ເອງໃນ TikTok ຫຼື ວາງໄຟລ໌ທີ່ມີສິດໃຊ້.
ເພງຖືກກົດລົງອັດຕະໂນມັດເວລາມີສຽງພາກ (sidechain); `music_vol` ປັບລະດັບ (0.2).

## ສຽງເອັບເຟັກ
ໃສ່ເອງຕາມເຫດການ: `impact` (ເປີດຄລິບ, `flash`), `whoosh` (ສາກປ່ຽນ whip/slide, quote), `pop` (ກາດສະຖິຕິ, ປຸ່ມຕິດຕາມ),
`tick` (ປ້າຍຊື່), `tear` (ກາດບົດ, ຕອນຈົບ). ໄຟລ໌ຈິງໃນ `<library>/SFX/whoosh*`, `impact*`, `pop*`, `tear*`, `tick*` ຈະຖືກໃຊ້ແທນສຽງສັງເຄາະ. `sfx: off` ໃນສ່ວນຫົວ = ປິດທັງໝົດ.

## ການຜະສົມ
ສຽງພາກ (ປັບໃຫ້ແຈ້ງ ຊັດ): highpass 90 Hz → ຫຼຸດສຽງອູ້ 250 Hz → ເພີ່ມຄວາມຊັດ 3.5 kHz → ເພີ່ມຄວາມໃສ 8 kHz → compressor → -16 LUFS. ລວມທັງໝົດ → **-14 LUFS, true peak -1.5 dB**, AAC 192 kbps 48 kHz.
ໄຟລ໌ແຍກ `_stem_voice.wav`, `_stem_music.wav`, `_stem_sfx.wav` ສຳລັບ CapCut.
