# ສຽງພາກ, ເພງ ແລະ ສຽງເອັບເຟັກ

## ສຽງພາກ (`voice:`)
| ຄ່າ | ແມ່ນຫຍັງ | ໃຊ້ຕອນໃດ |
|---|---|---|
| `file:voice.m4a` | ສຽງອັດຂອງ Joe / ທອງດຳ (mp3, m4a, wav, mp4 ໄດ້ໝົດ) ວາງໃນໂຟນເດີໂປຣເຈັກ | **ຄຸນນະພາບດີສຸດ** — ຄລິບຈິງທຸກຄລິບ |
| `mms` (ຄ່າເລີ່ມຕົ້ນ) | ສຽງ AI ລາວ ອອບລາຍ (Meta MMS-TTS, ONNX, CPU). ໄດ້ເວລາຂອງທຸກຄຳແບບເປ໊ະ | ຮ່າງ, ທົດລອງບົດ, ຄລິບບໍ່ຫວັງກຳໄລ (ລິຂະສິດ CC BY-NC 4.0) |
| `edge:female` / `edge:male` | Microsoft `lo-LA-KeomanyNeural` / `lo-LA-ChanthavongNeural` ຜ່ານ `pip install edge-tts` | ສຽງ AI ທີ່ທຳມະຊາດກວ່າ. ຕ້ອງການອິນເຕີເນັດເປີດ + websocket → **ແລ່ນບໍ່ໄດ້ໃນ cloud sandbox** (ຍັງບໍ່ໄດ້ທົດສອບໃນນີ້); ໃຊ້ໃນຄອມຂອງ Joe |

### ຂັ້ນຕອນເມື່ອ Joe ອັດສຽງເອງ
1. ຂຽນ `script.md` ໃຫ້ຈົບ → ສົ່ງຂໍ້ຄວາມພາກ (ບໍ່ມີ `[…]`) ໃຫ້ Joe ອ່ານຕາມລຳດັບ ແຖວຕໍ່ແຖວ.
2. ວາງໄຟລ໌ສຽງໃນໂປຣເຈັກ, ຕັ້ງ `voice: "file:ຊື່ໄຟລ໌"`.
3. ລະບົບຈະ: ຕັດຊ່ວງງຽບທີ່ຍາວກວ່າ 0.35 ວິ ອອກ (`tighten: false` ເພື່ອປິດ), ຫາຈຸດຢຸດຫາຍໃຈ, ແລ້ວຈັບຄູ່ປະໂຫຍກກັບສຽງ
   (ແຕ່ລະປະໂຫຍກໄດ້ເວລາຕາມສັດສ່ວນຄວາມຍາວ ແລະ ຕັດຕົງຈຸດຢຸດ). ຄຳບັນຍາຍຈຶ່ງກົງລະດັບປະໂຫຍກ; ພາຍໃນປະໂຫຍກແມ່ນປະມານ.
4. Joe ຕ້ອງອ່ານ **ຕາມບົດ ບໍ່ຂ້າມ ບໍ່ສະຫຼັບແຖວ**. ຖ້າອ່ານຜິດແລ້ວອ່ານຄືນ → ຕັດສ່ວນຜິດອອກກ່ອນ ຫຼື ແກ້ບົດໃຫ້ກົງ.
5. ສຽງອັດ: ກາດ "ບົດທີ N" ຖືກປິດ (ບໍ່ມີຊ່ອງງຽບໃຫ້ແຊກ) — ຊື່ບົດຂຶ້ນເປັນປ້າຍມຸມຊ້າຍເທິງແທນ.

### ຄຳອ່ານ (`say:`) ສຳລັບສຽງ AI
- ສຽງ AI ອ່ານໄດ້ສະເພາະໂຕລາວ. ທຸກຄຳໂຕລາຕິນຕ້ອງມີຄຳອ່ານ; `check` ບອກຄຳທີ່ຂາດ.
- ຕົວເລກ, ເປີເຊັນ, ຜົນການແຂ່ງຂັນ, `ໆ` → ລະບົບແປງເອງ (`2014` → ສອງພັນສິບສີ່, `2-1` → ສອງ ຕໍ່ ໜຶ່ງ, `52.6%` → ຫ້າສິບສອງຈຸດຫົກ ເປີເຊັນ).
- ຄຳອ່ານຍາກ ໃຫ້ແຍກພະຍາງ ແລະ ທົດລອງ 2–3 ແບບ; Claude ຟັງສຽງບໍ່ໄດ້ → ຂໍ Joe ຟັງຢືນຢັນ ແລ້ວເກັບຄຳອ່ານທີ່ຖືກໄວ້ໃຊ້ຕໍ່.
- ຢາກໃຫ້ຢຸດຫາຍໃຈ: ໃສ່ຈຸດ `,` ຫຼື ຍະຫວ່າງ. `speed:` ປັບຄວາມໄວ.

## ເພງ (`music:`)
ລຳດັບ: `music.*` ໃນໂປຣເຈັກ → ທີ່ຢູ່ໄຟລ໌ໃນ `music:` → ຄັງ `<library>/MUSIC/<ເດືອດ|ລຸ້ນ|ເສົ້າ|ມ່ວນ>/` → **ເພງສັງເຄາະ** (pad + bass ເບົາໆ, ບໍ່ມີລິຂະສິດ).
ຄັງ: ຕັ້ງ `LAOSTUDIO_LIBRARY=/path/ຄັງ` ຫຼື `"library": ["/path"]` ໃນ brand json. ຄັງຂອງ Joe ຢູ່ Dropbox `1. ALL IN/marketing/` (ໂຟນເດີ `MUSIC/`, `SFX/`).
ເພງສັງເຄາະເປັນພຽງພື້ນ; ຖ້າ Joe ຢາກໄດ້ເພງດັງ ໃຫ້ໃສ່ເອງໃນ TikTok ຫຼື ວາງໄຟລ໌ທີ່ມີສິດໃຊ້.
ເພງຖືກກົດລົງອັດຕະໂນມັດເວລາມີສຽງພາກ (sidechain); `music_vol` ປັບລະດັບ (0.2).

## ສຽງເອັບເຟັກ
ໃສ່ເອງຕາມເຫດການ: `impact` (ເປີດຄລິບ, `flash`), `whoosh` (ສາກປ່ຽນ whip/slide, quote), `pop` (ກາດສະຖິຕິ, ປຸ່ມຕິດຕາມ),
`tick` (ປ້າຍຊື່), `tear` (ກາດບົດ, ຕອນຈົບ). ໄຟລ໌ຈິງໃນ `<library>/SFX/whoosh*`, `impact*`, `pop*`, `tear*`, `tick*` ຈະຖືກໃຊ້ແທນສຽງສັງເຄາະ. `sfx: off` ໃນສ່ວນຫົວ = ປິດທັງໝົດ.

## ການຜະສົມ
ສຽງພາກ: highpass 75 Hz → ເພີ່ມຄວາມຊັດ 3.2 kHz → compressor → -16 LUFS. ລວມທັງໝົດ → **-14 LUFS, true peak -1.5 dB**, AAC 192 kbps 48 kHz.
ໄຟລ໌ແຍກ `_stem_voice.wav`, `_stem_music.wav`, `_stem_sfx.wav` ສຳລັບ CapCut.
