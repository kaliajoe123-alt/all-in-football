## ແຖວພາກ
```
# ຊື່ບົດ                                   ← ບົດທຳອິດບໍ່ມີກາດ; ບົດຕໍ່ໄປຂຶ້ນກາດ "ບົດທີ N"
[ຄຳສັ່ງ | ຄຳສັ່ງ | …] ຂໍ້ຄວາມທີ່ພາກ ມີ *ຄຳສຳຄັນ* ໃນດາວ
// ແຖວທີ່ຂຶ້ນຕົ້ນ // ແມ່ນໝາຍເຫດ (ບໍ່ອ່ານ)
```

| ຄຳສັ່ງ | ຄວາມໝາຍ |
|---|---|
| `img: ຄຳຄົ້ນ` | ຮູບ. ຄຳຄົ້ນ **ພາສາອັງກິດ** (ຊື່ຄົນ + ທີມ/ປີ/ຕຳແໜ່ງ). ຫຼາຍຮູບໃນປະໂຫຍກດຽວ: `img: A; B`. ເລືອກຜົນອັນດັບອື່ນ: `Ederson #2`. ຫຼື ຊື່ໄຟລ໌ໃນ `assets/` |
| `video: ຄຳຄົ້ນ` | ຄລິບສະຕັອກ (Commons/Pexels); ບໍ່ມີ → ໃຊ້ຮູບແທນ |
| `clip: ໄຟລ໌.mp4@12.5` | ຄລິບຂອງ Joe ໃນ `assets/` ຫຼື ຄັງ, ເລີ່ມວິນາທີທີ 12.5 (ບໍ່ໃສ່ @ = ກາງຄລິບ) |
| `label: ຊື່` | ປ້າຍເຫຼືອງ ມຸມລຸ່ມຊ້າຍ — **ຕ້ອງກົງກັບຄົນໃນຮູບ** |
| `stat: 52.6% = ຈ່າຍບານສຳເລັດ` | ກາດສະຖິຕິ (ຄ່າ = ຄຳອະທິບາຍ). ຢູ່ຕະຫຼອດປະໂຫຍກ |
| `quote: ຂໍ້ຄວາມ — ຜູ້ເວົ້າ` | ແຖບຄຳເວົ້າ (ສະເພາະຄຳເວົ້າຈິງທີ່ມີແຫຼ່ງ) |
| `text: ຂໍ້ຄວາມໃຫຍ່ *ເນັ້ນ* // ແຖວສອງ` | ກາດຂໍ້ຄວາມລ້ວນ (ບໍ່ມີຮູບ); `//` = ຂຶ້ນແຖວໃໝ່ |
| `src: ແຫຼ່ງຂໍ້ມູນ` | ແຫຼ່ງຂອງຕົວເລກ/ຄຳເວົ້າ → ລົງ `_credits.txt` |
| `full` / `card` | ບັງຄັບເຕັມຈໍ / ໃນກາດ |
| `flash` | ແຟລັຊຂາວ + ສຽງ impact + ຊູມ (ຈຸດພີກ) |
| `tr: cut\|pop\|slide\|whip\|tear` | ບັງຄັບສາກປ່ຽນ |
| `sfx: pop\|whoosh\|impact\|tear\|tick\|none` | ສຽງເອັບເຟັກຕອນເລີ່ມແຖວ |
| `slow` | ຄລິບຊ້າ 2 ເທົ່າ |
| `nocap` | ແຖວນີ້ບໍ່ຂຶ້ນຄຳບັນຍາຍ |

ບໍ່ໃສ່ `img` → ໃຊ້ຮູບຕໍ່ໄປຂອງຄຳຄົ້ນກ່ອນໜ້າ. ປະໂຫຍກຍາວກວ່າ ~4.4 ວິ ຈະຖືກແບ່ງເປັນຫຼາຍຊັອດເອງ (ໃສ່ `img: A; B` ເພື່ອກຳນົດຮູບຂອງແຕ່ລະຊັອດ).

## ກົດການຂຽນ (ພາສາລາວສຳລັບພາກສຽງ)
1. **Hook ໃນ 3 ວິ**: ຄຳຖາມ ຫຼື ຄຳຢືນຢັນທີ່ຂັດຄວາມເຊື່ອ. ບໍ່ທັກທາຍ, ບໍ່ແນະນຳຊ່ອງ.
2. **ປະໂຫຍກດຽວ = ຄວາມຄິດດຽວ**, 8–16 ຄຳ. ຍາວກວ່ານີ້ໃຫ້ຕັດເປັນສອງແຖວ.
3. ພາສາເວົ້າ ສຸພາບ ເປັນກັນເອງ: "ຮູ້ບໍ່ວ່າ…", "ຄຳຖາມຄື…", "ແຕ່ເລື່ອງບໍ່ຈົບເທົ່ານັ້ນ". ໃຊ້ "ລາວ" ແທນບຸກຄົນ, "ເຮົາ" ແທນຜູ້ເລົ່າ.
4. ຄຳສັບເຕະບານ: ຜູ້ຮັກສາປະຕູ, ກອງຫຼັງ, ກອງກາງ, ກອງໜ້າ, ເຂດໂທດ, ລະດູການ, ແຊ້ມ, ຄະແນນ, ນັດ, ຍິງປະຕູ, ເຊຟ, ຈ່າຍບານ, ຄ່າຕົວ, ບານເຕະໂລກ, ພຣີເມຍລີກ.
5. **ຊື່ສະເພາະ**: ຂຽນໂຕລາຕິນໃນຂໍ້ຄວາມ (Manuel Neuer) + ຄຳອ່ານໃນ `say:` (ມານູເອລ ນອຍເອີ). ຊື່ປະເທດ/ລີກທີ່ມີຄຳລາວ ໃຫ້ຂຽນລາວເລີຍ (ເຢຍລະມັນ, ອັງກິດ).
   ຄຳອ່ານໃຫ້ສະກົດງ່າຍ: ຫຼີກຕົວຄວບທີ່ອ່ານຍາກ (Claudio → ຄາວດິໂອ), ແຍກພະຍາງດ້ວຍຍະຫວ່າງ.
6. **ຕົວເລກ** ຂຽນເປັນເລກ: ປີ `2014`, ທົດສະນິຍົມ `2.21`, ເປີເຊັນ `74%`, ຜົນ `2-1`, ຫຼັກພັນ `35,000`. ຫົວໜ່ວຍຂຽນເປັນຄຳລາວ (ລ້ານປອນ, ແມັດ, ຄະແນນ).
7. ທຸກ 3–4 ແຖວ ມີ `stat`, `label`, `text` ຫຼື `quote` ຢ່າງໜ້ອຍໜຶ່ງ → ຈໍບໍ່ນິ້ງ.
8. ໝາຍ `*ຄຳສຳຄັນ*` 1 ວັກຕໍ່ແຖວ (ຊື່ຄົນ, ຕົວເລກເດັ່ນ, ຄຳພີກ) → ຂຶ້ນສີແດງໃນຄຳບັນຍາຍ.
9. ແຖວສຸດທ້າຍ = ຄຳຖາມໃຫ້ຄອມເມັ້ນ ("ເຈົ້າຄິດວ່າ…? ຄອມເມັ້ນບອກກັນແດ່!").
10. ຄວາມຍາວ: ສຽງ AI ອ່ານ ~2.2 ຄຳ/ວິ. 12 ແຖວ ≈ 90 ວິ · 17 ແຖວ ≈ 2.5 ນາທີ · 40 ແຖວ ≈ 5–6 ນາທີ · 80–100 ແຖວ ≈ 12–15 ນາທີ (ຄືຕົວຢ່າງ).
