## ໂຄງສ້າງບົດຂອງຕົວຢ່າງ (ຈາກການຖອດສຽງ)
1. **0:00–1:00 ເປີດດ້ວຍປົມ** — ບໍ່ທັກທາຍ; ເລົ່າບັນຫາທັນທີ, ໃສ່ຄຳຖາມຂອງແຟນບານ ("ເປັນຫຍັງ Pep ບໍ່ແກ້ຈຸດອື່ນກ່ອນ?"), ມີມຸກປຽບທຽບ.
2. **~1:00–1:30 ສັນຍາ** — "ໃນຄລິບນີ້ເຮົາຈະ…" + ຄຳຖາມຫຼັກ 1–2 ຂໍ້ ທີ່ຄລິບຈະຕອບ.
3. **~1:30–2:00 ສະປອນເຊີ** (ຖ້າມີ) ແລ້ວ "ກັບມາເລື່ອງຂອງເຮົາກັນຕໍ່".
4. **ບົດເນື້ອໃນ 3–5 ຕອນ** — ທີ່ມາ/ປະຫວັດ → ຫຼັກຖານເປັນຕົວເລກ → ມຸມມອງກົງກັນຂ້າມ → ຈຸດຫັກ.
5. **ບົດສະຫຼຸບ** — ຕອບຄຳຖາມຫຼັກ, ຄວາມເຫັນຂອງຜູ້ເລົ່າ, ຖາມຄົນເບິ່ງ.
ປະໂຫຍກສັ້ນ 1.5–4 ວິ, ນ້ຳສຽງລົມກັນ (ບຸລຸດທີ 1), ທຸກ 20–30 ວິ ມີ "ຕົວເລກ" ຫຼື "ຊື່ຄົນ" ຂຶ້ນຈໍ.

## ສິ່ງທີ່ສະບັບລາວດີກວ່າ
- ຄຳບັນຍາຍລາວ word-by-word (ຫຼາຍຄົນເບິ່ງແບບປິດສຽງ) + ໄຟລ໌ `.srt`.
- ຫົວຂໍ້ hook ໃຫຍ່ໃນ 3 ວິທຳອິດ + ແຟລັຊ + ສຽງ impact; ໜ້າປົກສ້າງອັດຕະໂນມັດ.
- ປ້າຍຊື່ບົດ ແລະ ແຖບຄວາມຄືບໜ້າ → ຄົນເບິ່ງຮູ້ວ່າຢູ່ຕອນໃດ, ເບິ່ງຈົນຈົບຫຼາຍຂຶ້ນ.
- ສຽງດັງມາດຕະຖານ -14 LUFS; ເພງຫຼົບສຽງພາກອັດຕະໂນມັດ.
- ບົດດຽວອອກໄດ້ທັງ 16:9 ແລະ 9:16.
- ທຸກຮູບມີເຄຣດິດ + ລິຂະສິດ (`_credits.txt`), ທຸກຕົວເລກມີແຫຼ່ງ (`src:`) → ປອດໄພຕໍ່ການຖືກລຶບ ແລະ ໜ້າເຊື່ອຖື.
- ຈົບດ້ວຍປຸ່ມ "ກົດຕິດຕາມ" + ຄຳຖາມໃຫ້ຄອມເມັ້ນ.
